# Decisions

- No AI framework: focused modules keep each pattern reviewable.
- Deterministic mocks by default: startup, tests, and demos need no key.
- Exact SQLite caching: predictable identity and TTL; no semantic claims.
- In-memory token bucket: clear single-process limitation.
- One structured correction: bounded recovery from malformed provider output.
- No LLM judge: evaluation remains deterministic and offline.
- XYFlow: graph interaction is a first-class product feature.
- No generic executable workflow builder: the canvas explains a fixed architecture.
