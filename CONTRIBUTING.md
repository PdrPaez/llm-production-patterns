# Contributing

Create a card such as `LPP-035`, branch from `dev` using `feature/LPP-035-description` (or the matching fix/test/docs prefix), validate the focused behavior, then commit as `[AREA][LPP-035] concise English description`. Run backend Ruff/pytest and frontend lint/build for affected areas. Merge integration work into `dev`; promote only validated releases to `main`.
